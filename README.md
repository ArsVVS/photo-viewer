# Фото проводник (PhotoExplorer)

Просмотрщик изображений для Windows по образцу FastStone Image Viewer: слева дерево папок и предпросмотр,
справа сетка миниатюр текущей папки. Миниатюры кешируются в SQLite, поэтому повторное открытие папки
происходит мгновенно. Есть поиск, сортировка, полноэкранный просмотр со слайд-шоу и консольная утилита.

## Возможности

- дерево папок с разделом «Избранное»;
- сетка миниатюр с виртуализацией, три размера миниатюр, выделение нескольких файлов (Ctrl / Shift);
- панель предпросмотра с разрешением, размером и датой файла;
- сортировка по имени, дате, размеру и типу; фильтр по типу;
- поиск по имени или маске (`*`, `?`);
- кеш миниатюр в SQLite;
- полноэкранный просмотр: масштаб колесом мыши, перетаскивание, поворот, панель EXIF, слайд-шоу;
- переименование, удаление в корзину, окно свойств, контекстное меню;
- светлая и тёмная тема;
- консольная утилита `photos` для списка файлов, поиска, EXIF и работы с кешем.

Поддерживаемые форматы: JPEG, PNG, BMP, GIF (первый кадр), WebP. Список расширений меняется в настройках.

Используемые библиотеки: SkiaSharp (декодирование и уменьшение изображений), MetadataExtractor (EXIF),
Microsoft.Data.Sqlite (кеш), CommunityToolkit.Mvvm, VirtualizingWrapPanel, System.CommandLine, xUnit.

## Запуск

```
dotnet build
dotnet test
```

Запуск графического приложения:

```
dotnet run --project src/PhotoExplorer.Wpf
```

```
PhotoExplorer.Wpf.exe C:\Photos            # открыть папку
PhotoExplorer.Wpf.exe C:\Photos\img.jpg    # открыть папку и сразу показать файл на весь экран
```

Настройки хранятся в `%APPDATA%\PhotoExplorer\settings.json`, кеш миниатюр – в `%LOCALAPPDATA%\PhotoExplorer\thumbs.db`.
